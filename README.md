# 🎧 Spotify Clone + Admin Panel

This is a full-stack **Spotify Clone** built using the **MERN Stack** with **TailwindCSS**, featuring a dedicated **Admin Panel** for managing content.

> Built with 💚 by **Anush Jadhav**

---

## 🛠️ Tech Stack

- **Frontend**: React + TailwindCSS (`spotify-clone`)
- **Backend**: Node.js + Express.js (`spotify-admin`)
- **Database**: MongoDB
- **Admin Panel**: Custom-built (React + TailwindCSS)
- **Stack**: MERN (MongoDB, Express, React, Node.js)

---

## 📁 Project Structure

```bash
project-root/
├── spotify-clone/    # Main user-facing frontend (React + Tailwind)
├── spotify-admin/    # Admin Panel backend (Node + Express)
├── admin/            # Admin Panel frontend (React + Tailwind)
├── .gitignore
├── README.md
└── package.json

🚫 No Auth (Yet!)
Currently, the project does not have a Signup/Login feature, but it provides an Admin Panel for full control over the platform.


🌟 Features
🎵 Stream Music: Spotify-like user interface to play songs and albums.
⚙️ Admin Panel: Manage songs, albums, artists, and more from a custom-built admin interface.
💨 Responsive Design: Fully responsive UI built with TailwindCSS, optimized for all screen sizes.
⚡ Fast: Optimized performance for smooth music streaming and content management.
🧱 Modular Architecture: Scalable, modular structure that’s easy to extend and maintain.
